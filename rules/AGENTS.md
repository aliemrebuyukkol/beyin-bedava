# Beyin-Bedava activation rules (v3)
Activate only for explicit game intent or credible game-project evidence. Opening a project triggers read-only SCAN, not code changes. Find SKILL.md relative to installed skill or workspace; do not assume a host loads this file automatically. For a requested bug fix preserve scope; for implementation or new game creation, generate an itemized checklist covering all applicable skill capabilities (`plan_game_integration.py plan ... --all-capabilities --branch-agents`), branch out across parallel specialist agents (`task_ledger.py ready`), invoke `monetization-gate-agent` upon project approval to ask whether Ad Placements and/or Paywall/IAP integration is desired (`none | ads | paywall | both`) and activate accordingly, complete 100% of the checklist without leaving partial work, and run `task_ledger.py audit-completion --restart-incomplete` to verify and automatically restart any incomplete or failed branch until 100% verified. No live billing, unsolicited monetization, churn-targeted matchmaking, hidden outcome manipulation, or destructive changes. Follow the skill's execution and quality protocols; report real test evidence and blockers. Non-game repositories remain untouched.
