# Progression, levels, worlds and repetition
Build a mechanic introduction matrix: teach safely, practice with feedback, combine with prior skills, test mastery, offer optional challenge. Alternate novelty, mastery and recovery. Define milestones with actual content IDs and prerequisites; validate reachable paths, save/resume, no softlocks, deterministic rewards and replayability. Do not gate essential progress behind ads or paid randomness.
For each level specify goal, twist, layout, challenge, estimated duration (hypothesis), failure/retry, unlock and accessibility. Track mechanic/biome/objective combinations to avoid cosmetic-only repetition. Reuse systems rather than duplicate code; procedural content requires seeded generation, reachable routes and constraints.
Economy: model sources/sinks with scenarios (novice, average, expert, absent player); show time-to-unlock distribution and no-spend route. Reward mastery, creativity and discovery. No punitive decay. Include content budget, art/audio ownership and migration for existing saves.
