# Reference library
Primary starting points (check current versions and licenses before use):
- Self-Determination Theory: https://selfdeterminationtheory.org/
- MDA: https://users.cs.northwestern.edu/~hunicke/MDA.pdf
- Game Programming Patterns: https://gameprogrammingpatterns.com/
- Game Accessibility Guidelines: https://gameaccessibilityguidelines.com/
- Quantic Foundry: https://quanticfoundry.com/ (commercial survey research; not universal)
- GDC Vault: https://www.gdcvault.com/
- Apple HIG: https://developer.apple.com/design/human-interface-guidelines/
- SpriteKit: https://developer.apple.com/documentation/spritekit
- RealityKit: https://developer.apple.com/documentation/realitykit
- Godot examples: https://github.com/godotengine/godot-demo-projects
- Three.js: https://github.com/mrdoob/three.js
- Flame: https://github.com/flame-engine/flame
Do not treat patents, gambling research, commercial survey results or synthetic benchmarks as proof of effects in a particular game. Log source, claim, population, limitation and date when using evidence. These links are reference suggestions, not independently verified by the skill.
