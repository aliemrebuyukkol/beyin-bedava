# Game feel, interaction and polish
Create an input-to-feedback map for each core action. Measure input latency, frame pacing and touch target sizes on actual hardware where possible. Use fixed-step physics with interpolation where appropriate, stable collision rules, predictable momentum, explicit cancellation and recovery states. Tune acceleration, deceleration, dead zones, camera damping and collision response in a test scene, not blindly.
Motion: purposeful easing, spatial continuity, readable anticipation/follow-through, bounded camera shake, configurable reduced motion. Audio: clear event hierarchy, spatial cues where useful, mute and volume controls; haptics optional, non-essential. Never communicate essential information by color, sound or vibration alone.
Test interruptions, background/resume, orientation/safe areas, touch conflicts, low frame rates, large text, color contrast and input alternatives. Establish device-specific CPU/GPU/memory/thermal budgets and measure percentiles, not average FPS alone. Do not claim 60 fps without measurement.
