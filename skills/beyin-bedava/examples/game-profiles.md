# Example routing profiles (illustrative, not executed games)
| Profile | Include | Exclude by default | Acceptance hypothesis |
|---|---|---|---|
| Finger swimming | Swift adapter, alternating input, physics, race milestones | hidden rubber-banding, paid advantage | synchronized strokes reward timing consistently |
| Cozy camp | discovery, expression, non-punitive progress, game feel | matchmaking, loss lockout, forced ads | a missed day never removes earned items |
| Horror | input, light/audio, authored tension, checkpoint recovery | gacha, session manipulation | threat is legible without unfair input |
| Child myth education | learning objectives, accessibility, privacy, playful recall | behavioral ads, paid RNG, pressure | child can demonstrate learning after interaction |
| Competitive racing | fair matchmaking, shared physics, latency | churn targeting, hidden DDA | same inputs and state produce same rules |
